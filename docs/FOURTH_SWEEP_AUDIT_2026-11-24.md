# 第四輪程式可靠性與 UI／UX 稽核

日期：2026-11-24。基準為 PR #5 最新提交 `05812029`（兩組 Windows CI 已通過）。本輪獨立分支接續 PR #5，未修改 main 或使用者原始素材。

## 已確認並修正

1. **跨磁碟成品提交**：目的檔已發布後，若來源 TEMP 因鎖定而刪除失敗，不應再將已完成的輸出視為失敗。改為保留 TEMP 並發出警告，避免誤重跑；清理錯誤不得掩蓋原始寫入錯誤。
2. **暫停／續轉狀態機**：修正已取消的 AbortSignal 可能讓安全邊界永久等待，以及同步訂閱者立即續轉時的通知順序競態。允許撤回尚未到達安全邊界的暫停要求；新工作清空舊工作的資源、片段與 ETA，取消／失敗不再顯示過期 ETA。
3. **成品庫並行匯入**：媒體探測期間其他任務可能先加入同一路徑；於序列化寫入時再去重，更新新增及重複計數，避免記憶體與重開後列表數量不一致。
4. **字幕正式發布**：保存已通過驗證的同一份位元組，防止驗證後重新讀取另一版本的草稿。BACKUP 且原正式檔不存在時，採不可覆蓋的原子建立，避免覆寫剛出現的檔案。

## UI／UX

- 共用成品庫區分載入、失敗與真正空清單；讀取失敗提供重試，複製路徑後提供可讀的成功提示。
- 以請求序號避免過期的非同步查詢覆蓋最新成品列表；新增 MP4 過程禁用重複匯入及重整操作，提供進行中回饋。
- 成品庫與歷史紀錄窄視窗的操作列、標題和確認區可換行，並調整小視窗對話框邊距及高度上限。
- 增加讀取狀態與錯誤的無障礙語意；不更改現有視覺品牌或操作架構。

## 驗收與界限

- 新增單元與 renderer 回歸測試，覆蓋故障注入、競態、暫停取消、字幕完整性與載入／錯誤狀態。
- CI 以本 PR 最新提交的 FFmpeg 8.1.2／latest Windows 矩陣結果為準。
- CSS 為靜態審查及針對性修正，尚未以 Electron 實機截圖驗收 100%／125%／150% 縮放、小螢幕與不同 DPI。不可宣稱整站視覺品質或全部 UI 已驗收。
- 長影片效能、跨實體磁碟續轉、真實雲端服務、正式封裝及字幕跨多檔斷電交易性仍需獨立驗收。不得因此刪除使用者資料或放寬現有保護。
