## 直接修復紀錄

1. 專案切換重設字幕影片選擇、分析 checkpoint、AI 檢查狀態；跨專案安全阻擋與 UI 全面清理。
2. 獨立字幕工作區以 projectId 隔離，重複匯入影片不覆蓋舊草稿；源媒體 URL 隨切換撤銷。
3. Electron 只允許載入已指定的應用程式來源，拒絕不可信頁面與新視窗繼承 preload。
4. YouTube resumable 308 不再把無 Range 當作成功接收，檢查偏移值並限制無進度重試。
5. 修正 `bytes=-500` 等 HTTP 尾段範圍，防止媒體播放器讀錯檔案位置。
6. FINAL_OUTPUT 與 Render TEMP 分別使用各自磁碟 reserve，避免系統 C: 錯套資料碟配額。
7. 只有明確 `ENOSPC/-28` 證據才分類為磁碟已滿，避免把一般 mux/trailer 錯誤誤判成磁碟故障。
8. 補強 FFmpeg 取消回歸、專案 ID、IPC、Electron URL、續傳、封裝來源和 UI 切換測試。
9. 套件安全修補與鎖檔升級；一次性 CI 格式化與修補 workflow 已清除。

## 尚未取得的驗收證據（不可宣稱 PASS）

- 真正使用者的 4K 長片、多磁碟 C:/E: 跨卷 Resume、備援、拔碟與系統低空間實驗。
- Google OAuth 與對真實頻道的影片上傳，包含長時間中斷後工作階段恢復；YouTube 回應模擬通過不等於服務端 E2E。
- OpenAI/Gemini 有額度的真實逐字稿／字幕品質與成本驗收。
- 完整 Windows 可攜包及實體音效素材來源的授權、SHA 與執行驗收。封裝前需要 `SCENERYWALKER_SHUTTER_MP3` 或 `assets/camera-shutter-click-14671.mp3`。
- 實機音訊、多聲道、不同 GPU 編碼器、縮放比例、遠端手機與網路品質組合。
- TEMP 通用 Artifact 清理在缺乏可安全判斷獨立性證據時仍故意拒絕刪除，**不要為求功能表面可用而放寬保護**。
