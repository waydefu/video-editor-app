# UI 設計規格（字體、字級、按鈕、間距）

2026-11-25 依全介面量測制定。改介面時照這份走；數值都定義成 `src/renderer/styles.css` 開頭 `:root` 的 CSS 變數，元件樣式只引用變數，不寫死數字。

量測基準（制定前）：208 種不重複按鈕，高度 17～61px 有十幾種、內距十幾種、圓角 7 種、字級 11～15px。

## 1. 字體

- 中文：微軟正黑體；英文與數字：Segoe UI 斜體。全部文字（含按鈕、輸入框、時間碼）都套用（負責人決定；原本的標楷體已取消）。
- 字體堆疊：`"Segoe UI", "Microsoft JhengHei UI", "Microsoft JhengHei", "微軟正黑體", sans-serif`。拉丁字母由 Segoe UI 顯示，中日韓字元與全形標點落到微軟正黑體。
- `font-style: italic` 設在 `:root`，`input`、`textarea`、`select`、`button` 都 `font: inherit`。
- `font-synthesis: weight`：只允許合成粗體，禁止合成斜體，所以中文維持正體、只有英文數字是斜體。

## 2. 字級（根字級 18px，可由「Aa 設定」整體縮放）

| 變數       | 值        | 約等於 | 用途                        |
| ---------- | --------- | ------ | --------------------------- |
| `--fs-xs`  | 0.6875rem | 12.4px | 小標（eyebrow）、徽章、角標 |
| `--fs-sm`  | 0.75rem   | 13.5px | 說明文字、欄位標籤、小按鈕  |
| `--fs-md`  | 0.8125rem | 14.6px | 內文、按鈕、輸入框（預設）  |
| `--fs-lg`  | 0.9375rem | 16.9px | 區塊標題、強調數值          |
| `--fs-xl`  | 1.125rem  | 20.3px | 對話框標題                  |
| `--fs-2xl` | 1.5rem    | 27px   | 頁面標題                    |

主畫面大標（hero）維持原本尺寸，不在此表內。舊值歸併：≤0.6875→xs；0.72～0.78→sm；0.8～0.82→md；0.875～1→lg；1.0625～1.25→xl；1.375～1.75→2xl。

## 3. 按鈕

三種尺寸，依「重要程度與所在位置」決定，不依原本長相：

| 尺寸            | 高度 | 左右內距 | 字級    | 圓角 | 用在哪                                                                       |
| --------------- | ---- | -------- | ------- | ---- | ---------------------------------------------------------------------------- |
| 大 `lg`         | 40px | 18px     | md、700 | 8px  | 對話框頁尾的主要動作、主畫面兩個起始按鈕                                     |
| 中 `md`（預設） | 34px | 14px     | md、600 | 8px  | 工具列、對話框內一般動作、表單                                               |
| 小 `sm`         | 28px | 10px     | sm、600 | 6px  | 卡片與清單列內的動作、上移／下移／移除、播放／開啟位置等行內小動作、分段切換 |

- 只有圖示或符號的按鈕：正方形，邊長等於該尺寸高度，必須有 `aria-label`。
- 外觀四種：主要（藍底白字，每個畫面最多一個）、次要（深色底＋細框，預設）、文字（透明底）、危險（紅字紅框，用於刪除／清除／中斷授權）。
- 危險動作（刪除、清除、解除授權）執行前要確認。
- 每個畫面最多一個主要按鈕；只有「完成／關閉」一顆時它可以是主要按鈕，但同時有其他主要動作時「完成／關閉」改次要。
- 平台品牌按鈕（YouTube／TikTok／BiliBili）沿用次要按鈕尺寸，只保留品牌色邊框。
- 停用：不透明度 0.45、游標 not-allowed，不改尺寸。
- 懸停不再上浮位移，只換底色與框色，避免畫面跳動。
- 例外「磚塊型按鈕」不套高度：色彩預設卡、選項格、縮圖、清單項目整列可點的按鈕。它們只統一圓角（12px，`--card-radius`）與字級刻度。
- 狀態徽章、版本標籤這類膠囊用 999px 圓角。

## 4. 間距

- 刻度：4／8／12／16／24／32px（`--space-1`～`--space-6`）。只用這六個值。
- 對話框：頁首 16px 24px、內容 16px 24px、頁尾 12px 24px，都不設固定最小高度；區塊之間 16px；同組欄位之間 8～12px。
- 按鈕之間 8px；頁尾按鈕靠右對齊。
- 卡片內距 16px；清單列內距 8px 12px。
- 非刻度值就近換算：3、5→4；6、7、9→8；10→間距 8／內距 12；11、13→12；14→間距 12／內距 16；15、17～20→16；21、22→24；26、28→24；30→32。1～2px 的框線不動。
